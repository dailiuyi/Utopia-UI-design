# 视觉规范

## 方向与参考层级

目标是《攻壳机动队》的配色与科技风格。未指定版本时，以 1995 剧场版冷峻、克制的气质作为项目设计起点；用户指定 S.A.C.、ARISE 或其他版本/画面时据此调整，不将不同版本视为同一套官方设计系统。

官方作品参考：[系列官网的 1995 剧场版介绍](https://theghostintheshell.jp/en/introduction/article/ghost-in-the-shell)、[Production I.G 作品介绍与剧照入口](https://www.production-ig.co.jp/works/ghost-in-the-shell)。这些是作品出处，不提供本项目的精确色表或现成 UI 组件。下述配色与界面表达是设计提炼，不是逐帧取色结论；无需联网也可按本文与变量工作。

随包 [主题海报](../assets/reference-posters/theme.png)、[赛道海报](../assets/reference-posters/tracks.png) 保留原图，辅助参考分区、切角与机械线稿。其黑黄配色、宋体大标题、赛事名不再支配当前客户端风格。作品或海报中的角色、标志与台词不自动成为游戏资源。

## 配色语义

[design-tokens.json](../assets/design-tokens.json) 是数值来源。以冷黑和青灰建立空间层次，电子绿突出主动作，青色用于定位与次级信息线；冷白保证中文可读，琥珀与红色用于明确的异常状态。

| 变量 | 用途 |
|---|---|
| background / surface / surfaceRaised | 冷黑背景、深青灰面板、抬升层，避免一片纯黑或玻璃卡片 |
| brand / brandPressed / onBrand | 电子绿主动作与选中标记，按下略暗，实色按钮上使用深色文字 |
| accent | 青色定位角框、坐标轴、必要的信息连接线，不与主动作抢权重 |
| textPrimary / textSecondary | 冷白正文与灰青次文字，重要提示不用细线颜色 |
| borderStrong / borderSubtle | 功能边界与低对比分隔，装饰不围满所有组件 |
| warning / danger | 琥珀警告与红色危险，始终配图标、说明与恢复动作 |
| disabledSurface / disabledText | 清楚可辨的禁用状态，同时说明无法操作的原因 |

大部分面积保持深色与中性，绿色和青色集中在可行动区域及有意义的线条。不要全屏染绿，不把真实相机套成电影滤镜，也不将紫蓝霓虹、全屏 Bloom 或高亮绿色代码雨当作默认“科技感”。

保留目标项目的玩家身份色，例如红蓝方块仍使用红蓝；结合名称、位置、形状区分，不因主题绿色而丢失身份或危险语义。成功状态结合对勾与明确文字，不能仅靠与主色相同的绿。

## 科技感如何落到页面

| 视觉语言 | 客户端表达 | 约束 |
|---|---|---|
| 冷峻空间与机械层次 | 冷色深浅面板、少量原创装配线稿、局部结构编号 | 准备页可丰富，战斗中心保留实景与角色 |
| 电脑信息界面 | 主状态、对象身份、动作与反馈分层；短标签配等宽数值 | 不新增没有数据源的坐标、延迟、置信度或百分比 |
| 精密框架 | 细直线、角括号、短刻度、克制切角 | 线条指向真实对象/区域，装饰框不等于触摸区 |
| 定位扫描 | 局部扫描线、目标边界、匹配阶段变化 | 反馈真实定位状态，动画结束不等于匹配成功 |
| 网络与连接感 | 有意义的节点关系、连接状态、清晰的失连恢复入口 | 不编造网络拓扑或装饰性的实时数据流 |
| 警告系统 | 琥珀局部标记、必要时一小段警示纹；危险使用红色 | 普通按钮、页眉和所有边框不默认贴斜纹 |

科技感来自结构、状态反馈与精确排版。隐藏装饰后，用户仍应看懂该做什么。不要用科幻词替代“加入房间”“重新扫描”等直白动作。

## 字体、几何与动效

中文标题、按钮与正文以清晰黑体/无衬线为主，标题通过字重与留白建立层级；数值与短编号使用等宽或等宽数字。衬线标题仅用于用户指定的特定参考，不强制所有页面套宋体海报排版。正文不增加大字距，不用密集英文和极小字号伪装专业感。

`Noto Sans CJK SC` 可作中文候选，实施时核验字体文件许可、字重与打包配置；桌面系统回退不代表字体会随 Unity 发布。数字、计时不能因字宽变化跳动。

采用变量中的 8 单位间距、1–2 单位细线、8–16 单位切角。它们是参考画布单位，非手机物理像素。重要相机叠层使用足够遮蔽的深色底板；底板透明度与边线需在亮墙、日光、暗室和复杂背景实测。

按下约 120 ms、面板过渡约 200 ms、阶段切换约 320 ms 是可调起点。扫描只在局部活动，不持续全屏闪烁。减少动态效果时移除扫描与装饰运动，状态文字仍清楚；输入不等待动画。

## 组件与验收

主按钮为电子绿实底深字，次按钮为深底冷白字，选中态增加实心标记。定位组件用青色框与明确阶段；错误组件用琥珀/红色图标、短说明和恢复动作。HUD 仅显示实际玩法需要的计时、身份、生命或回合；本身没有生命值的项目不额外加血条。

检查准备、定位、游戏各页，分别看明暗与复杂相机背景、窄屏与长文本。验证功能信息层次、角色可见度、触摸区与真实状态；不能只在黑色设计板上判断可读性，也不能把生成图视为可交互客户端。
