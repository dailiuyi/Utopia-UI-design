## 从海报迁移到客户端

| 海报特征 | 客户端表达 | 应约束的范围 |
|---|---|---|
| 黑底与明黄块面 | 黑色面板、黄色主动作、黑字黄底选中项 | 战斗中央保留相机与角色，黄色不覆盖整个视野 |
| 中文宋体/明朝体大标题 | 准备页、倒计时短标题、结算标题使用粗衬线字 | 正文、生命值、提示、按钮使用清晰无衬线字 |
| 英文衬线字与大编号 | 少量章节号、回合号、辅助短标题 | 中文承担完整含义，不做满屏双语重复 |
| 45 度切角细框、角括号 | 弹窗、角色选择、状态面板、定位取景角 | 装饰框不等于触摸区域，禁用按钮仍要可辨认 |
| 黑黄斜纹警示带 | 页首细条、局部定位警示或过渡标识 | 不全屏滚动、不围住每个组件、不能只靠斜纹表达错误 |
| 机械线稿、暗色渐变 | 准备页的原创机械结构线、结算底纹 | 战斗时明显减弱或隐藏；不覆盖角色轮廓、血条和正文 |
| 大留白与强分区 | 一页一个主动作、明显主次级别 | 不堆虚构数据、乱码、无意义准星或仪表 |

## 颜色与文字

以 [design-tokens.json](../assets/design-tokens.json) 为唯一数值起点。颜色经人工取意制定，未声明是海报精确取色。

- 黄色为品牌强调与可行动区域，黑/近黑为底板，奶白为主要文字，浅灰米色为次级文字。
- 警告使用品牌黄配图标和说明；错误/危险可用有限红色，同时给出文字或符号。不要为了“统一黑黄”让成功、失败、禁用状态无法区分。
- 玩家与对手用位置、名称、头像/轮廓、`我方/对手` 区分；生命值配明确数量或量尺，不能只靠不同颜色。
- 相机背景上的重要文字必须有足够遮蔽的深色底板；透明度要在亮墙、阳光、暗室与复杂背景上验证，不能只在黑色设计稿上看对比。
- 中文标题优先选项目已获许可且可打包的宋体/明朝体；正文使用中文黑体。没有字体资产时标记待选，不声称操作系统字体会自动随 Unity 打包。
- `Noto Serif CJK SC` / `Noto Sans CJK SC` 可作为候选家族，实施时核验所选字体文件许可、字重和打包配置。系统 `SimSun` / `Songti SC` 只可作为桌面预览回退，不能据此假定手机效果。
- 数字、计时和短编号用等宽或等宽数字特性。提示尽量一句话，例如“对准已登记的场景，缓慢移动手机”。

## 几何、材质和动效

8 单位间距节奏，2 单位主边线、1 单位弱分隔，8–16 单位切角。尺寸指参考画布单位，落地后检查缩放清晰度，不等于手机物理像素。

面板为实色或高遮蔽深色；轻微暗黄过渡只用于大面积背景。不要默认用实时毛玻璃、全屏 Bloom、色差或厚重外发光。工业感来自结构与排版，而非叠满特效。

建议交互反馈约 120 ms、面板过渡约 200 ms、阶段切换约 320 ms，实际数值可调。按下反馈用短暂填充/边线变化；定位提示可用缓慢局部扫描线，但无持续全屏闪烁。减少动态效果设置下移除扫描和装饰运动，状态变化仍可读。

战斗受击反馈应由真实战斗事件驱动；震屏、闪屏和触觉不是默认必做。输入响应不等待装饰动画完成。

## 组件外观约定

| 组件 | 基础表现 | 状态差异 |
|---|---|---|
| 主按钮 | 明黄底、黑色文字、少量切角 | 按下变深；禁用采用灰暗底并说明原因，不仅降低透明度 |
| 次按钮 | 深底、奶白字、细框 | 选中加入实心标记；不与主动作竞争 |
| 定位提示 | 局部黑底、步骤标题、一句操作指引 | 扫描/匹配/绑定/失败用明确文案；无 SDK 进度就不用百分比 |
| 生命条 | 深色轨道、清楚填充、名称和数值 | 低生命可加危险符号；扣血残影是可选效果 |
| 操作模块 | 与共享 HUD 分开的区域 | 直接操作、指令、观战、未定分别提供布局；只激活选定模块 |
| 错误面板 | 深底、短错误说明、恢复主动作 | 定位重试、去设置、返回等按真实故障选择 |

## 视觉验收

分别检查竖屏准备、竖屏定位、横屏战斗。准备界面可以像海报，战斗界面要在真实光照背景上可读。缩到手机实际尺寸后检查中文、数字和按钮，不以桌面大图代替。先隐藏所有装饰，若流程仍清晰，再逐步恢复纹理；不影响信息读取的装饰才保留。
